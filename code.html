EVEWorld: Physical Evolution Supervision for Embodied World Models

The code release accompanying the paper under double-blind review. The snapshot is hosted on anonymous.4open.science with history and authorship stripped, and it contains the method core, the pinned backbone snapshots, and the benchmark pipelines exactly as used for the reported results.

Why this page is static. The interactive repository browser on anonymous.4open.science is a JavaScript application. Depending on how the page is opened — in particular when it is opened in a new tab from another page — the browser may block that script, and the repository view then stays blank. This page carries no script at all, and the snapshot download below is a direct file transfer, so both work in every case. If the interactive repository view does render for you, the rendered README is the friendliest way to read the release.

What the snapshot contains

eveworld/Method core: IGR corruption and restoration, TIA correspondence, training entry points, the MLR metric, evaluation tooling, and the five alternative designs analyzed in the paper.
giga-world-0/Pinned snapshot of the GigaWorld-0 backbone: model package, configs, training and inference scripts.
giga-models/Pinned snapshot of the GigaModels training framework used by the backbone.
benchmarks/Evaluation pipelines: DreamGenBench, WorldArena 1.0, EWMBench (AgiBot), RoboTwin-FlowWAM, PBench, and the cross-model baselines.
docs/Environment setup, data preparation, and end-to-end reproduction guides.
index.htmlThe interactive project page with the qualitative video comparisons.
